#

> **[EN]**
1. Copy the `loku-hud` folder into your FiveM server's `resources` folder.
2. Place the `fivem-hud` folder on your desktop and run the following commands in the terminal:
```bash
cd fivem-hud
npm install
npm run build
```
   
This will create a dist folder.

3. Copy the `dist` folder into `resources/loku-hud/` and rename it to `html`.
4. Activate the HUD from the server console or in `server.cfg`:

```bash
ensure loku-hud
```

#

> **[TR]**
1. `loku-hud` klasörünü FiveM sunucunuzun `resources` klasörüne kopyalayın.
2. `fivem-hud` klasörünü masaüstüne koyun ve terminalde aşağıdaki komutları çalıştırın:
```bash
cd fivem-hud
npm install
npm run build
```
   
Bu işlem sonunda dist klasörü oluşacaktır.

3. dist klasörünü resources/loku-hud/ içine kopyalayın ve adını html olarak değiştirin.
4. Sunucu console veya server.cfg üzerinden HUD'u aktif edin:

```bash
ensure loku-hud
```

**Lisans: Bu script serbest kullanım içindir; isteyen istediği şekilde kullanabilir, değiştirebilir ve dağıtabilir.**
