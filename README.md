

resources -> loku-hud klasörünü fivem resources klasörü içine koy.

`fivem-hud` klasörünü **masaüstüne** koy:

```bash
cd fivem-hud
npm install
npm run build

```

Oluşan dist klasörünü resources içinde bulunan loku-hud içine koy ve adını 'html' olarak değiştir.

resources içinde olan loku-hud klasörünü (client.lua ve fxmanifest.lua bulunan) fivem resources içine koy ve ensure loku-hud
